# Emergency Exit Signage, Egress Lighting & Stairway

Asset ID(s): **NSF-EX-ALL (21 exit signs), NSF-EM-ALL (49 emergency lights), NSF-DR-ALL (7 fire doors)**. Quantity: 77. Location: Stair B and egress routes, every floor.

Every floor has one enclosed, fire-rated emergency stairway (Stair B) fitted with SafeGuard LumaExit illuminated exit signage, SafeGuard LumaPath emergency corridor lighting, and Ironclad FD60 fire-rated doors with panic-bar hardware.

## Technical specifications

| Spec | Value |
|---|---|
| Exit signage | SafeGuard LumaExit LED, 3-hour battery backup, 21 units |
| Emergency lighting | SafeGuard LumaPath LED bulkhead, 49 units (corridors, stair, core) |
| Stairway doors | Ironclad FD60 fire-rated door set with panic bar hardware, 7 units (1/floor) |
| Stairway rating | 60-minute fire resistance, pressurised/vented enclosure |
| Discharge point | Ground floor (Floor 1) — direct exterior door to grade |
| Elevator use during alarm | Prohibited — elevators auto-recall to Floor 1 |
